Project Overview

What is CrewOne HR?

CrewOne HR is a custom-built, web-based HR management system designed for small-to-medium companies. It replaces manual attendance registers, paper leave forms, and scattered communication — bringing everything into one secure, mobile-friendly platform.

The system supports two roles: Admin (full control) and Employee (self-service). All data is stored securely in a PostgreSQL database (Neon) and deployed on Vercel with zero downtime.

Security

Security & Access Control

Role-based access

Admin and Employee roles — each can only access their own pages and APIs.

Password hashing

All passwords stored as bcrypt hashes (cost factor 10). Plain passwords stored separately for admin reference only.

JWT session cookies

HttpOnly cookies — cannot be accessed by JavaScript. Sessions expire automatically.

Server-side auth checks

Every API endpoint and admin page verifies session on the server — no client-side only protection.

Parameterized SQL queries

All database queries use prepared statements — no SQL injection possible.

Environment variables

Database credentials and secrets stored in Vercel environment variables — never in code.
